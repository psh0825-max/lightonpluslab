Sidekey 크롬판 판매·환불 안내

시행일 2026·10·30 · 최종 수정 2026·10·30

라이트온 플러스 랩(LightOn Plus Lab, 이하 "판매자")이 판매하는 Chrome 확장 프로그램 Sidekey 크롬판 라이선스의 판매 조건입니다. Google이 판매하는 상품이 아니며, 판매자는 라이트온 플러스 랩입니다.

상품과 가격

  • 상품 — Sidekey 크롬판 라이선스(Sidekey Chrome Pro)
  • 가격 — 일회성 결제 9,900원(부가가치세 포함). 정기 결제가 아니며 추가 요금이 없습니다.
  • 사용 범위 — 라이선스 1개로 Chrome 브라우저 프로필 2개까지 인증할 수 있습니다. 데스크톱(Windows)판은 포함하지 않습니다.
  • 유료 기능 — 새 금고 생성, API 키 등록·수정. 확장 프로그램 설치와 기존 금고의 열람·복사·암호화 백업·복원은 라이선스 없이도 사용할 수 있습니다.

결제와 제공 방법

  • 결제는 확장 프로그램의 구매 버튼으로 열리는 외부 결제 페이지에서 진행합니다. 결제·영수증·세금 처리는 결제 대행사 Lemon Squeezy, LLC가 판매 대행(Merchant of Record)으로 담당합니다.
  • 결제가 끝나면 라이선스 키가 결제 시 입력한 이메일로 즉시 발송됩니다. 확장 프로그램의 라이선스 화면에 키를 입력하면 바로 사용할 수 있습니다.
  • 확장 프로그램은 카드 정보를 받지 않습니다.

이용 조건

  • Chrome 137 이상이 필요합니다.
  • 라이선스 상태는 하루에 한 번 온라인으로 확인합니다. 마지막 확인 후 최대 7일까지는 인터넷 연결 없이 사용할 수 있습니다.
  • 확장 프로그램을 삭제하기 전에 라이선스 화면에서 등록을 해제하면 다른 프로필에서 다시 사용할 수 있습니다. 해제하지 못한 채 재설치했다면, 새 프로필에서 확인 후 가장 오래 사용하지 않은 등록을 교체할 수 있습니다(30일에 3회). 그 이상은 문의해 주세요.
  • API 키와 금고 내용은 이용자의 브라우저에만 암호화되어 저장됩니다. 마스터 비밀번호를 잊으면 판매자도 금고를 복구할 수 없으니 암호화 백업을 보관해 주세요.

청약철회와 환불

  • 구매 후 7일 이내에는 사유와 관계없이 전액 환불합니다. 라이선스 인증이나 사용 여부는 묻지 않습니다.
  • 7일이 지난 후에도 상품이 이 안내나 광고와 다르거나 계약 내용과 다르게 제공된 경우, 「전자상거래 등에서의 소비자보호에 관한 법률」 제17조 제3항에 따라 제공받은 날부터 3개월 이내, 그 사실을 안 날 또는 알 수 있었던 날부터 30일 이내에 환불을 요청할 수 있습니다.
  • 부분 환불은 하지 않으며, 환불은 결제 금액 전액을 원래 결제 수단으로 취소하는 방식으로 진행합니다.
  • 환불을 요청하시려면 support@lightonpluslab.com으로 주문번호 또는 결제에 사용한 이메일을 보내 주세요. 접수일로부터 3영업일 이내에 결제를 취소하며, 카드사·결제 수단에 따라 실제 환급까지 며칠이 더 걸릴 수 있습니다.
  • 환불되면 해당 라이선스가 사용 중지되어 새 금고 생성과 키 등록·수정이 제한됩니다. 이미 저장한 키의 열람·복사와 암호화 백업·복원은 계속 사용할 수 있습니다.

업데이트와 지원

  • 판매자는 Chrome 웹 스토어를 통해 확장 프로그램 업데이트를 제공하며, 이메일로 문의를 받습니다.
  • 라이선스 인증 서비스를 종료하게 되면 이 페이지와 확장 프로그램 설명에 사전에 알립니다. 종료 후에도 브라우저에 저장된 금고의 열람·복사·암호화 백업은 계속 사용할 수 있습니다.

개인정보

라이선스 인증에 필요한 정보만 처리하며, API 키와 금고 내용은 전송하지 않습니다. 자세한 내용은 Sidekey 크롬판 개인정보 처리방침을 확인해 주세요.
