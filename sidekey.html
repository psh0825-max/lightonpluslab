An API-key vault for Chrome.

Sidekey is a Chrome extension from LightOn Plus Lab for storing, finding and copying API keys you already own. Organize keys by name, service, tags and notes. Your vault is encrypted locally with your master password.

Core features

  • Create an encrypted vault and add, edit or delete API keys.
  • Find and copy saved keys; export and restore encrypted backups.

No API keys, provider accounts, credits or AI usage are included or resold. The desktop (Windows) edition and desktop MCP features are separate and are not included in this Chrome license.

Free and Pro pricing

The Free plan includes installation, encrypted vault creation, adding, editing, copying and deleting up to 5 API keys, and encrypted backup and restore, with no time limit or card. Pro removes the 5-key limit for adding new keys. Pro is a one-time purchase, not a subscription: KRW 9,900 in Korea (VAT included), USD 6.99, JPY 1,100 or EUR 6.99 in other regions. The final price and taxes are shown on the checkout page. One license covers up to 2 Chrome browser profiles.

How it works

  1. Install from the Chrome Web Store. Chrome 137 or later is required.
  2. Start with the free 5-key plan. Purchase Pro through the external checkout page opened by the extension to add more than 5 keys.
  3. Create a vault with a master password of at least 12 characters. A paid license is not required to create the free vault.
  4. Add your own API keys. Keep your password and an encrypted backup safe: we cannot recover a forgotten master password.

Your data stays under your control

Vault contents and your master password are not sent to our licensing server. License verification uses a license key or renewal token and a random browser identifier. Copying puts a key on your device clipboard; clear it after use. Backups are encrypted files you choose to save.

The extension locks when its popup closes or after five minutes of inactivity. Pro is verified online once a day and works offline for up to 7 days after the last verification. When Pro ends because of a refund, license revocation or verification expiry, existing keys remain readable, editable, copyable and deletable, including keys above the free limit. Encrypted backup and restore remain available. Only adding a new key beyond the free 5-key limit is blocked without active Pro. Keep your own encrypted backups.

Favorites, recent copies and optional metadata export

Favorites and recent copies are stored only inside your encrypted local vault. Optional MCP export contains metadata only, with no API-key values or master password. It does not inject secrets into another app or provide a live MCP connection.

Payments, refunds and support

The external checkout page is operated by Polar Software, Inc. (USA) as Merchant of Record and authorized reseller. Polar handles payment, receipts, taxes and refunds. LightOn Plus Lab provides the software license and product support. The extension does not receive card details. After payment, Polar emails your license key, which is also available in Polar’s customer portal. Existing Lemon Squeezy orders remain with their original payment provider.

You can request a full refund for any reason within 7 days of purchase. Refunds are processed through Polar, and the license is automatically deactivated after a full refund. Mandatory consumer rights are not limited. To request a refund or get help, contact support@lightonpluslab.com with your order number or purchase email. Never send API keys or your master password.

Chrome에서 쓰는 나만의 API 키 금고.

Sidekey는 LightOn Plus Lab이 만드는 Chrome 확장 프로그램입니다. 이미 보유한 API 키를 이름·서비스·태그·메모로 정리하고 검색·복사합니다. 금고는 마스터 비밀번호로 암호화되어 브라우저에 저장됩니다.

주요 기능

  • 암호화 금고 생성과 API 키 등록·수정·삭제
  • 저장한 키 검색·복사와 암호화 백업·복원

API 키, 서비스 계정, 크레딧 또는 AI 사용량을 판매하거나 제공하지 않습니다. 데스크톱(Windows)판과 데스크톱 MCP 기능은 별도 제품이며 Chrome 라이선스에 포함되지 않습니다.

무료와 Pro 가격

무료 플랜은 확장 프로그램 설치, 암호화 금고 생성, API 키 5개까지 등록·수정·복사·삭제, 암호화 백업·복원을 기간 제한 없이 카드 등록 없이 제공합니다. Pro는 새 키 추가 한도 5개를 해제합니다. Pro는 정기 결제가 아닌 일회성 구매이며, 가격은 한국 9,900원(부가가치세 포함), 해외 USD 6.99 / JPY 1,100 / EUR 6.99입니다. 최종 가격과 세금은 결제 화면에 표시됩니다. 라이선스 1개는 Chrome 브라우저 프로필 최대 2개에 적용합니다.

이용 방법

  1. Chrome 웹 스토어에서 설치합니다. Chrome 137 이상이 필요합니다.
  2. 키 5개까지 무료로 시작합니다. 5개를 넘는 키를 추가하려면 확장 프로그램에서 여는 외부 결제 페이지에서 Pro를 구매합니다.
  3. 12자 이상의 마스터 비밀번호로 금고를 만듭니다. 무료 금고 생성에 유료 라이선스는 필요하지 않습니다.
  4. 보유한 API 키를 등록합니다. 비밀번호와 암호화 백업을 안전하게 보관해 주세요. 잊어버린 마스터 비밀번호는 복구할 수 없습니다.

내 데이터는 내가 관리

금고 내용과 마스터 비밀번호는 당사 라이선스 서버로 전송하지 않습니다. 라이선스 확인에는 라이선스 키 또는 갱신 토큰과 무작위 브라우저 식별자를 사용합니다. 복사한 키는 기기의 클립보드에 남으므로 사용 후 지워 주세요. 암호화 백업은 사용자가 선택한 파일로 저장합니다.

팝업을 닫거나 5분 동안 사용하지 않으면 잠깁니다. Pro 라이선스는 하루에 한 번 온라인으로 확인하며, 마지막 확인 후 최대 7일까지 오프라인으로 Pro를 사용할 수 있습니다. 환불·라이선스 취소·인증 만료로 Pro가 종료되어도 5개를 넘는 기존 키를 포함하여 열람·수정·복사·삭제와 암호화 백업·복원이 가능합니다. 활성 Pro가 없으면 무료 한도 5개를 초과하는 새 키 추가만 제한합니다. 암호화 백업을 별도로 보관해 주세요.

즐겨찾기·최근 복사·선택적 메타데이터 내보내기

즐겨찾기와 최근 복사 기록은 암호화된 로컬 금고 안에만 저장됩니다. 선택적 MCP 내보내기는 메타데이터만 포함하며 API 키 값과 마스터 비밀번호를 포함하지 않습니다. 다른 앱에 비밀 값을 주입하거나 실시간 MCP 연결을 제공하는 기능은 아닙니다.

외부 결제 페이지는 Polar Software, Inc.(미국)가 운영하며, 판매 대행(Merchant of Record) 및 공식 재판매자로서 결제·영수증·세금·환불을 담당합니다. LightOn Plus Lab은 소프트웨어 라이선스와 제품 지원을 제공합니다. 확장 프로그램은 카드 정보를 받지 않습니다. 결제 후 Polar가 이메일로 라이선스 키를 보내며 Polar 고객 포털에서도 확인할 수 있습니다. 기존 Lemon Squeezy 주문은 주문 당시 결제 제공자를 통해 처리합니다.

구매 후 7일 이내에는 사유와 관계없이 전액 환불합니다. 환불은 Polar를 통해 처리하며, 전액 환불 후 라이선스는 자동으로 비활성화됩니다. 법률상 제한할 수 없는 소비자 권리는 유지됩니다. 환불 요청이나 문의 시 주문번호 또는 구매 이메일을 support@lightonpluslab.com으로 보내 주세요. API 키나 마스터 비밀번호는 보내지 마세요.
