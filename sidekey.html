An API-key vault for Chrome.

Sidekey is a Chrome extension from LightOn Plus Lab for storing, finding and copying API keys you already own. Organize keys by name, service, tags and notes. Your vault is encrypted locally with your master password.

Core features

  • Create an encrypted vault and add or edit API keys.
  • Find and copy saved keys; export and restore encrypted backups.

No API keys, provider accounts, credits or AI usage are included or resold. The desktop edition and desktop MCP features are separate and are not included in this Chrome license.

Release and pricing

The launch candidate provides up to 5 API keys free with no time limit. You may explicitly start your first 14-day Pro evaluation without a card; it does not start automatically and never converts into a paid subscription. Pro allows adding more than 5 keys. One-time Pro pricing: KRW 9,900 (Korean VAT included), USD 6.99, JPY 1,100 or EUR 6.99. Review applicable local taxes and the final total before payment. A paid license covers up to 2 Chrome profiles. No purchase is available on this page.

How it works

  1. Install the Chrome extension from its official listing once released. Chrome 137 or later is required.
  2. Start with the free 5-key tier. Choose the cardless 14-day Pro evaluation only if you want to try adding more keys.
  3. Create a vault with a master password of at least 12 characters. A paid license is not required to create the free vault.
  4. Add your own API keys. Keep your password and an encrypted backup safe: we cannot recover a forgotten master password.

Your data stays under your control

Vault contents and your master password are not sent to our licensing server. License verification uses a license key or renewal token and a random browser identifier. Copying puts a key on your device clipboard; clear it after use. Backups are encrypted files you choose to save.

The extension locks when its popup closes or after five minutes of inactivity. When the evaluation ends, a refund is processed or Pro is no longer verified, existing keys remain readable, editable, copyable and deletable, including keys above the free limit. Encrypted backup and restore remain available. Only adding a key that would exceed the free 5-key limit is blocked without active Pro or evaluation access. Keep your own encrypted backups.

Favorites, recent keys and optional metadata export

The launch candidate adds favorites and recent-key organization stored on your device. Optional MCP-related export is limited to a metadata file: no API-key values or master password. It does not inject secrets into another app or imply a live MCP connection. These additions remain subject to implementation and verification before release.

Starting an evaluation uses a random, pseudonymous browser-profile identifier and a server-persisted expiry. It does not require payment data or invasive device fingerprinting. Deleting local data is not a promised way to restart an evaluation.

Payments, refunds and support

The linked existing policies describe the current product, not the proposed trial. Updated policies and trial-record retention details must be reviewed before this candidate launches.

The planned Polar checkout uses Polar Software, Inc. as Merchant of Record and authorized reseller. LightOn Plus Lab provides the software license and product support. The extension does not receive card details. Existing Lemon Squeezy orders remain associated with their original payment provider.

A paid purchase has a full-refund window of seven days for any reason. There is no payment to refund for the cardless evaluation and no automatic charge at its end. Existing purchases keep their applicable terms. Mandatory consumer rights are not limited. For help, contact support@lightonpluslab.com with your order number or purchase email. Never send API keys or your master password.

Chrome에서 쓰는 나만의 API 키 금고.

Sidekey는 LightOn Plus Lab이 만드는 Chrome 확장 프로그램입니다. 이미 보유한 API 키를 이름·서비스·태그·메모로 정리하고 검색·복사합니다. 금고는 마스터 비밀번호로 암호화되어 브라우저에 저장됩니다.

주요 기능

  • 암호화 금고 생성과 API 키 등록·수정
  • 저장한 키 검색·복사와 암호화 백업·복원

API 키, 서비스 계정, 크레딧 또는 AI 사용량을 판매하거나 제공하지 않습니다. 데스크톱판과 데스크톱 MCP 기능은 별도 제품이며 Chrome 라이선스에 포함되지 않습니다.

출시와 가격

출시 후보는 API 키 5개까지 기간 제한 없이 무료로 이용할 수 있도록 준비하고 있습니다. 사용자가 직접 시작하는 최초 14일 Pro 체험에는 카드가 필요 없고, 자동 시작이나 종료 후 자동 유료 전환은 없습니다. Pro에서는 5개를 넘는 키를 추가할 수 있습니다. Pro 일회성 가격은 한국 9,900원(부가가치세 포함), USD 6.99, JPY 1,100, EUR 6.99입니다. 해외 적용 세금과 최종 결제액은 결제 전에 확인합니다. 유료 라이선스 1개는 Chrome 프로필 최대 2개에 적용합니다. 이 페이지에서는 아직 구매할 수 없습니다.

이용 방법

  1. 정식 배포 후 공식 스토어에서 확장 프로그램을 설치합니다. Chrome 137 이상이 필요합니다.
  2. 키 5개까지 무료로 시작합니다. 더 많은 키를 추가하는 기능을 체험하고 싶을 때만 카드 없는 14일 Pro 체험을 직접 시작합니다.
  3. 12자 이상의 마스터 비밀번호로 금고를 만듭니다. 무료 금고 생성에 유료 라이선스는 필요하지 않습니다.
  4. 보유한 API 키를 등록합니다. 비밀번호와 암호화 백업을 안전하게 보관해 주세요. 잊어버린 마스터 비밀번호는 복구할 수 없습니다.

내 데이터는 내가 관리

금고 내용과 마스터 비밀번호는 당사 라이선스 서버로 전송하지 않습니다. 라이선스 확인에는 라이선스 키 또는 갱신 토큰과 무작위 브라우저 식별자를 사용합니다. 복사한 키는 기기의 클립보드에 남으므로 사용 후 지워 주세요. 암호화 백업은 사용자가 선택한 파일로 저장합니다.

팝업을 닫거나 5분 동안 사용하지 않으면 잠깁니다. 체험 종료·환불·Pro 인증 만료 후에도 5개를 넘는 기존 키를 포함하여 열람·수정·복사·삭제와 암호화 백업·복원이 가능합니다. 활성 Pro 또는 체험이 없으면 무료 한도 5개를 초과하게 되는 새 키 추가만 제한합니다. 암호화 백업을 별도로 보관해 주세요.

즐겨찾기·최근 사용·선택적 메타데이터 내보내기

출시 후보에는 기기에 저장하는 즐겨찾기와 최근 사용 정리를 준비하고 있습니다. 선택적 MCP 관련 내보내기는 메타데이터 파일에 한정하며 API 키 값과 마스터 비밀번호를 포함하지 않습니다. 다른 앱에 비밀 값을 주입하거나 실시간 MCP 연결을 제공한다는 뜻이 아닙니다. 이 추가 기능은 구현 및 검증을 마친 뒤 배포합니다.

체험을 시작할 때는 무작위 가명 브라우저 프로필 식별자를 사용하고 만료 시각을 서버에 보관합니다. 결제 정보나 침해적인 기기 지문 수집은 필요하지 않습니다. 로컬 데이터 삭제로 체험이 재시작된다고 보장하지 않습니다.

결제·환불·지원

연결된 기존 정책은 현재 제품 기준이며 신규 체험 조건을 반영한 최종 정책이 아닙니다. 출시 전에 변경 정책과 체험 기록 보유 기간을 검토해야 합니다.

도입 예정인 Polar 결제에서는 Polar Software, Inc.가 판매 대행 및 재판매자(Merchant of Record) 역할을 맡고, LightOn Plus Lab은 소프트웨어 라이선스와 제품 지원을 제공합니다. 확장 프로그램은 카드 정보를 받지 않습니다. 기존 Lemon Squeezy 주문은 주문 당시 결제 제공자를 기준으로 처리합니다.

유료 구매 후 7일 이내에는 사유와 관계없이 전액 환불합니다. 카드 없는 체험에는 결제가 없으므로 환불할 금액이나 종료 시 자동 청구가 없습니다. 기존 구매에는 구매 당시 조건이 적용됩니다. 법률상 제한할 수 없는 소비자 권리는 유지됩니다. 문의 시 주문번호 또는 구매 이메일을 support@lightonpluslab.com으로 보내 주세요. API 키나 마스터 비밀번호는 보내지 마세요.
