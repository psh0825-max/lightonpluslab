Lens · 기술 문서

무엇을 읽고, 어떻게 계산하고, 무엇을 못 하는가

Lens 는 CODE V 시퀀스 파일(.seq)과 Zemax OpticStudio 파일(.zmx)을 브라우저에서 열어 해석합니다. 해석 도구는 지원 범위를 모르면 쓸 수 없습니다 — 읽지 못한 명령을 조용히 넘기면 화면의 숫자가 설계와 다른 렌즈의 숫자가 되기 때문입니다. 이 문서는 읽는 명령, 읽지 않는 기능과 그때 대신 하는 일, 그래프마다의 축·단위·기준을 전부 적어 둔 것입니다.

읽는 파일과 지원 명령

두 형식 모두 텍스트 파일입니다. 화면에 끌어다 놓거나 붙여넣으면 바로 파싱합니다. 파싱과 이후 모든 계산은 브라우저 안에서 일어나고, 파일은 서버로 올라가지 않습니다.

CODE V 시퀀스 .seq

면 지정자는 SO·S1·S2…·SI 꼴을 씁니다. 아래 명령 외의 줄은 건너뜁니다.

분류명령읽는 내용
시스템LEN, TIT / TITLE, DIM, RDM, GO렌즈 시작·제목·치수 단위·반경/곡률 입력 모드·끝. GO 이후에는 내보낸 굴절률 표(! LLIDX)만 더 읽습니다.
파장WL, REF, WTW파장 목록, 기준 파장 번호, 파장별 가중치. 파장은 nm 으로도, 스펙트럼 문자 d·F·C·e·g 로도 적을 수 있습니다.
조리개 · 물체EPD, FNO, NA, NAO넷 중 마지막으로 읽은 하나가 조리개 지정이 됩니다.
필드XAN / YAN, XOB / YOB, XIM / YIM, XRI / YRI, WTF각도·물체높이·상높이·실상높이 중 파일에 나온 형식을 그대로 씁니다(AN → OB → IM → RI 순으로 찾습니다). WTF는 필드 가중치.
비네팅VUX, VLX, VUY, VLY필드별 상·하·좌·우 비네팅 계수.
면SO, S, STO, SI물체면·일반면·조리개면·상면. STO가 값 없이 혼자 오면 직전 면을 조리개로 바꿉니다. SI가 없으면 마지막 면을 상면으로 쓰고 경고합니다.
처방 수정RDY, CUY, THI, GLA, K면 지정자를 붙여 쓰는 LDM 편집(THI S3 1.2, RDY S4 -10 같은 꼴)도 읽습니다.
비구면ASP, A · B · C · D · E · F · G · H · J, K, CON, SPH원뿔상수와 4차~20차 계수. 계수 이름에 I는 쓰지 않습니다.
Forbes 비구면SPS QBF + SCOSCO의 K, NRADIUS, C3 이상을 Q-bfs 계수로 읽습니다. 그 밖의 특수면 형식은 모두 기저 원뿔면으로만 추적합니다.
구경CIR, CIR EDG, CIR OBS, REX / REY, ELX / ELY반구경·에지 두께 기준 구경·중심 차폐·사각 및 타원 구경.
편심 · 기울기XDE / YDE / ZDE, ADE / BDE / CDE, XOD / YOD / ZOD, ADX / ADY, DAR, BEN, REV, RETRET는 앞선 면의 국부 좌표계를 가져옵니다.
기타 면 속성SLB, PIM면 이름표와 상면 위치 자동 보정.
초점 이동NFO, FFO, IFO스루포커스 계산 개수·시작·증분.
주광선 조준CRA파장·필드·면·줌 위치별 조준점. CRA SI(상면 조준)는 무시하고 경고합니다.
사설 유리PRV … END, PWL뒤의 유리 절에서 설명합니다.
줌ZOO줌 위치 수와 위치별 값.
그 외WID, CA, TEL광각 모드·구경 계산 방식·물체공간 텔레센트릭(미지원, 경고).

파일 인코딩

OpticStudio 가 내보낸 .zmx 는 UTF-16 인 경우가 많고, BOM 이 없는 파일도 있습니다. 다음 순서로 판별합니다.

  • BOM 이 있으면 UTF-16 LE / BE
  • BOM 이 없어도 바이트의 홀수 또는 짝수 자리가 0 으로 채워져 있으면 UTF-16 로 봅니다
  • 그다음 UTF-8 (엄격 모드)
  • 그래도 실패하면 EUC-KR, 마지막으로 Latin-1

오래된 한글 주석이 들어간 .seq 가 EUC-KR 로 저장돼 있어도 제목과 면 이름표가 깨지지 않습니다.

어느 형식이든, 읽지 못한 항목이나 근사로 바꾼 항목은 파일을 열 때 경고로 모아 보여 줍니다. 경고가 비어 있으면 파일의 모든 내용이 그대로 들어왔다는 뜻입니다.

지원하지 않는 것

아래는 엔진이 스스로 경고를 내는 항목을 그대로 옮긴 것입니다. 읽지 않고 넘기는 것과, 근사로 바꿔 계산하는 것을 구분해 적었습니다 — 후자는 숫자가 나오지만 그 숫자가 설계와 다른 전제에서 나온 값입니다.

항목파일에 있는 것대신 하는 일
비순차 추적.zmx 의 NSC 데이터읽지 않습니다.
다중 구성Zemax multi-configuration파일에 저장된 상태 그대로만 불러옵니다.
특수면회절면(DOE·HOE), 자유곡면(XYP·ZFR·ODD), 사용자 정의면(UDS), Q-con(QCN)기저 원뿔면으로만 추적하고 면마다 경고합니다.
근축 이상렌즈paraxial / ideal lens 면두께 0 의 평면 더미면으로 추적합니다.
전역 좌표GLB두께만으로 면을 놓습니다.
굴절률 분포 유리GRIN 사설 유리(SEL·AXG·URN·LUN·SPG·MAX·UDG)읽지 않습니다.
용해 데이터PRV … MLT읽지 않습니다.
HAR 분산식PRV … HAR읽지 않습니다.
물체공간 텔레센트릭TEL조리개를 향해 광선을 조준합니다.
상면 주광선 조준CRA SI무시합니다.
곡면 물체곡률이 있는 SO평면으로 취급합니다.
물체면 편심·기울기SO 의 틸트·디센터무시합니다.
사각·타원 차폐rectangular / elliptical obscuration, 사용자 정의 구경무시합니다.
광각 모드WID + 유한 물체무한 물체에서만 지원합니다.
세오돌라이트 필드theodolite 각도보통 필드 각도로 읽습니다.
.zmx 조리개읽을 수 없는 시스템 조리개손으로 조리개 값을 넣어야 합니다.
.zmx 틸트일부 틸트·디센터 설정읽지 못한 항목을 경고합니다.
카탈로그 밖 유리공개 카탈로그에 없는 이름가까운 등가 유리로 치환하고, 바뀐 이름을 모두 알려 줍니다.

최적화와 공차 해석은 들어 있지 않습니다. Lens 는 이미 있는 설계를 열어 읽고 고쳐 보는 도구입니다. 최적화·공차·고스트 해석이 필요한 작업은 CODE V 나 OpticStudio 에서 하시는 것이 맞습니다.

해석 여섯 가지 — 계산 방식과 규약

같은 이름의 그래프라도 도구마다 기준이 다릅니다. RMS 를 반경으로 내는지 직경으로 내는지, 왜곡을 f·tanθ 로 보는지 f·θ 로 보는지에 따라 값이 2배, 혹은 몇 % 씩 갈립니다. Lens 가 쓰는 기준은 다음과 같습니다.

해석계산 방식규약
단면 · 1차 특성근축 추적과 실광선 추적렌즈 단면과 광선 경로를 그리고 초점거리·F수 같은 1차량을 함께 냅니다. 값을 고치면 같은 자리에서 다시 계산합니다.
스팟 다이어그램실광선 추적기준 파장의 주광선을 원점으로 삼습니다. RMS 는 중심(centroid) 기준 직경으로 냅니다 — 반경으로 보고하는 도구와 비교할 때는 2배 차이를 두고 보셔야 합니다.
MTF다색 회절 MTF동공 함수를 상공간 방향코사인으로 리샘플한 뒤, 정규좌표계에서 직접 자기상관을 취해 OTF 를 구합니다. FFT 격자에 얹지 않으므로 수 파장 이상 큰 수차에서도 위상 평균으로 변조가 깎이지 않습니다. 회절 한계는 같은 자기상관을 위상 없이 계산한 값이라 같은 격자·같은 동공에서 나온 비교 기준입니다. 접선(Y)과 시상(X)을 따로 냅니다.
스루포커스 MTF같은 회절 MTF를 초점 위치별로주파수 하나를 고르고 초점 이동 범위를 지정합니다. 화면의 초점 이동 프리셋은 ±5 · ±10 · ±20 · ±50 · ±100 µm 입니다.
광선 수차실광선 추적왼쪽은 접선(Y) — 동공 좌표 Py 에 대한 εy, 오른쪽은 시상(X) — Px 에 대한 εx. 단위는 µm.
필드 곡률비점수차 필드 곡선기준 파장에서 T(접선)는 실선, S(시상)는 점선. 단위는 mm.
왜곡두 기준을 함께f·tanθ 기준은 실선, f·θ 기준은 점선, 단위는 %. 광각 렌즈에서는 두 기준의 값이 크게 갈리므로 어느 쪽을 보고 있는지 확인하셔야 합니다.

유리와 분산 데이터

분산 데이터는 refractiveindex.info 데이터베이스(CC0 1.0 퍼블릭 도메인, 각 제조사 카탈로그 값)에서 가져온 것입니다. 모두 파장별 굴절률을 분산식으로 계산하며, nd·vd 보간이 아닙니다.

카탈로그

제조사유리 수

HIKARI363
CDGM314
HOYA190

여섯 제조사 1,615종에, 일반 재료 6종(SILICA, CAF2, SAPPHIRE, PMMA, POLYCARB, POLYSTYR)을 더해 모두 1,621종입니다. 제조사를 적지 않은 유리 이름은 SCHOTT → OHARA → HOYA → CDGM → HIKARI → SUMITA 순으로 찾습니다.

사설 유리 PRV

파일 안에 분산 계수를 직접 적는 사설 카탈로그를 읽습니다. 지원하는 형식은 LAU, GML, GMS, SLM, CAU 다섯 가지와, PWL 로 파장 목록을 주고 굴절률을 나열하는 표 방식입니다. HAR 분산식과 MLT 용해 데이터 피팅, GRIN 은 읽지 않고 경고합니다.

카탈로그에 없는 유리

공개 카탈로그에 없는 이름이 나오면 nd·vd 가 가까운 유리로 치환한 뒤, 바뀐 이름을 전부 경고에 적습니다. 치환된 유리의 성능 숫자는 원래 설계의 숫자가 아니므로, 경고에 이름이 올라왔다면 그 값을 그대로 쓰시면 안 됩니다.

조리개 형식(EPD / F수 / NA)과 필드 형식(각도 / 물체높이 / 상높이)은 화면에서 바꿀 수 있고, 바꿀 때 같은 렌즈가 되도록 값을 환산합니다. 환산이므로 원래 파일의 값과 표기가 달라 보일 수 있습니다.

용어

화면과 파일에 나오는 약어입니다.
