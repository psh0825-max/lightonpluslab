光学设计 · 免费

在浏览器里打开镜头文件

直接打开 CODE V 的 .seq 与 Zemax OpticStudio 的 .zmx，查看剖面与一阶特性、点列图、MTF、光线像差与场曲。无需安装，也不用注册。

打开 Lens 设计咨询

内置示例三片式 f50 F4。左为处方单，右为解析界面。

文件只在浏览器内计算，不会上传。 镜头处方本身就是设计，不是可以放到别人服务器上去分析的东西，所以把全部计算都放在浏览器里。从你放下文件的那一刻起，数据就不会离开这台电脑。

能看到什么

六个解析标签页。打开即计算并绘制。

01
剖面 · 一阶特性镜头剖面与光线路径，并同时读取焦距、F 数等一阶量。
02
点列图以基准波长主光线为参考，RMS 以质心（centroid）为基准的直径给出。
03
MTF同时绘出衍射极限，看得出还剩多少设计余量。离焦范围 ±5~50 µm。
04
光线像差左为子午（Y）εy 对瞳孔 Py，右为弧矢（X）εx 对 Px。单位 µm。
05
场曲 · 畸变像散场曲以 T 实线、S 虚线表示，畸变同时给出 f·tanθ 与 f·θ 两种基准。
06
玻璃SCHOTT、HOYA、OHARA、CDGM、SUMITA、HIKARI 六家共 1,598 种。来自 refractiveindex.info 的公开数据。

边改边看

不是只读查看器。改动表中数值，立刻重新计算。

面数据可直接修改半径、厚度、玻璃与半口径。半口径取自 CIR（用户光阑）或 CODE V 的默认光阑。
系统 · 视场 · 波长改变视场角与波长（nm）及权重，在不同条件下查看同一镜头。
变焦位置变焦镜头可切换各档位，查看每个位置的性能。

如何开始

拖入文件把 .seq 或 .zmx 文件拖到页面上即可打开，粘贴也行。
手头没有文件？内置示例镜头。可以先打开，把整个流程走一遍。
四种语言中文、English、한국어、日本語。也可切换为深色界面。

打开看看就好

无需注册、安装或上传。
