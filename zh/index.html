光学设计

在浏览器里打开镜头设计文件

直接打开 CODE V 的 .seq 与 Zemax OpticStudio 的 .zmx，查看光线追迹、点列图、MTF 与像差。文件只在浏览器内计算，不会上传到服务器。镜头处方本身就是设计，无法交给别人的服务器，所以做成了这样。

镜头数据面、半径、厚度、玻璃与折射率，像处方单一样读。
像差与畸变像散场曲（T·S）与以 f·tanθ / f·θ 为基准的畸变并排查看。
离焦 MTF在 ±5~50 µm 的离焦范围内查看各频率响应。
变焦位置可切换变焦位置查看，并内置可直接打开的示例镜头。
